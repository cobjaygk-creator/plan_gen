1. 왜 고치는가

개별 컴포넌트는 문제가 없습니다. 문제는 파일이 시간순 패치의 지층이 되었다는 점입니다. 같은 셀렉터를 아래쪽에서 계속 덮어쓰는 방식으로 쌓여, 지금은 한 값을 바꾸려면 파일 전체를 읽어야 실제 적용 값을 알 수 있습니다.

3. 삭제 목록

아래는 값을 바꾸는 게 아니라 지우는 항목입니다. 각 블록의 최종 승자만 남기고 위쪽 정의를 제거하면 파일이 대략 1,200줄대로 줄어듭니다.

3.1 중복 정의 블록

.ib-panel .headline 1~4번째, .ib-signal-tile.is-keyword 1~3번째, .ib-change-tile 컬러 border-top 정의(어차피 뒤에서 1px 회색으로 덮임), .ib-landscape-issue 1~2번째, .ib-watch-item .desc nowrap 버전.

3.2 죽은 셀렉터 — CSS와 JSX를 함께 제거

.ib-panel-accent, .ib-live-dot, .ib-signal-open, .ib-signal-detail, .ib-flip-in(animation:none으로 무력화됨), .ib-lnb-spacer. 숨기지 말고 마크업에서 지웁니다.

3.3 동작 제거 — 자동 로테이션

IndustryPanelCard.tsx의 DailyHighlightsBlock에서 6.5초 setInterval과 issuePage 상태를 삭제하고, coreIssues를 3건까지 전부 렌더합니다.

함께 제거: .ib-change-flap 키프레임과 animationDelay 인라인 계산, grid-template-rows: repeat(2, 150px) 고정 높이.

3.4 다크 블록 · 전용 웹폰트

.ib-highlight-core의 #141a2b 배색과 OneStoreMobileGothicTitleFont @font-face를 모두 제거합니다. 강조는 카드 배경이 아니라 위치(리드 카드 최상단) + 타입 크기로 만듭니다. 폰트 제거로 외부 CDN 의존도 하나 줄어듭니다.

5. 적용 순서

한 번에 다 바꾸지 말고 아래 순서로. 각 단계가 독립적으로 배포 가능합니다.

1
토큰 추가 + 색상 치환화면 변화 거의 없음. 다크모드가 이 단계에서 복구됩니다.
2
중복·죽은 셀렉터 삭제 (3.1 · 3.2)순수 정리. 최종 승자만 남기므로 렌더 결과는 동일해야 합니다 — 달라지면 삭제가 잘못된 것.
3
로테이션·다크블록·전용폰트 제거 (3.3 · 3.4)체감 변화가 가장 큰 단계. 여기서 한 번 팀 확인.
4
리드 카드 신설 + 이슈 목록 재구성시안 1a 기준. 백엔드 변경 없이 기존 필드 재배치로 가능합니다.
5
차트 y축 · 버블→표 · 시그널 표시안 2a. 데이터 구조는 그대로, 렌더링만 교체.
6
스켈레톤 · 빈 상태 · 진행 표시시안 1c. 실제 데이터가 비어 있는 날이 많으므로 체감 개선이 큽니다.

6. 검증 체크리스트

☐industry-brief.css 전체에서 #로 시작하는 색상 리터럴이 카테고리 색 2종 외에 남아 있지 않다
☐같은 셀렉터가 파일 안에서 2번 이상 등장하지 않는다
☐font-size 값이 토큰 6종 + 배지용 11px 외에 없다
☐모든 카드 padding이 var(--card-pad)이다
☐다크모드에서 흰 배경 카드가 하나도 남지 않는다
☐탭을 4개 모두 전환해도 헤더 높이가 변하지 않는다
☐60초 동안 화면을 그냥 두었을 때 어떤 텍스트도 자동으로 교체되지 않는다
☐데이터가 빈 날짜(예: 주말)로 이동했을 때 각 탭이 전용 빈 상태를 보여준다
☐페이지 전체를 캡처했을 때 호버 없이도 모든 그래프 수치를 읽을 수 있다
