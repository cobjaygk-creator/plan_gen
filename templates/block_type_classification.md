## 확정된 것 / 미확정인 것

**미확정 (원본 pptx 육안 확인 또는 사용자 확인 필요)**:
1. **202502 슬라이드9** — B/D 중 애매. 리본형 이미지가 뭘 의미하는지 원본 확인 필요.
2. **202506 슬라이드7** — 텍스트 추출이 부실해서 타입 판정 불가. 아이템명이 이미지 안에
   박혀있어 텍스트로 안 뽑히는 케이스일 수 있음 (이 경우 OCR이나 원본 열람 필요).
3. **202508 슬라이드7/8 vs 202605/202603 슬라이드7** — 둘 다 "이미지+캡션 그리드"인데
   전자는 이미지가 크고(60~160pt) 후자는 작음(24x24). **A와 E를 이미지 크기로 가를지,
   아니면 같은 타입으로 통합할지 설계 판단이 필요합니다.** 설계서 5장 정의(A=소형 아이콘,
   E=이미지+캡션 3열-위치매칭)가 크기 기준인지 매칭방식 기준인지 불명확 — 3.3 원칙(위치
   기반 매칭)은 사실 A/E 공통으로 적용 가능해 보여서, 매칭 방식이 아니라 **이미지 크기가
   진짜 구분 기준**인 것 같습니다. 확인 부탁드립니다.
4. **202602 슬라이드7 표=2** — 설계서가 지목한 버그 파일의 실제 증상일 가능성. 정답셋에서는
   제외(설계 원칙대로) 하되, 회귀 채점기가 이런 증상을 어떻게 잡아낼지 4단계에서 참고자료로만 사용.
5. **202606 슬라이드7** — "NEW" 텍스트 배지가 없는데 구조는 B'/D와 비슷함. 신규 패턴일 수
   있음 (설계서 5장: "새 타입 발견되면 표에 추가").
