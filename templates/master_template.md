# 마스터 템플릿 (기준: samples/202605_result.pptx, 2026년 5월)

정상 파일(3월/5월류) 중 가장 최근인 5월 샘플에서 추출. 원본 pptx는 다시 열지 말고
이 문서 + `master_template_summary.json` (좌표 상세)만 참고할 것. 재추출이 필요하면
`tools/extract_template.py` → `tools/summarize_template.py` 순서로 재실행.

## 슬라이드 규격
- 960pt x 540pt (16:9, EMU 기준 12,192,000 x 6,858,000)

## 폰트
- 본문 기본: **맑은 고딕** (테마 minor font, Hang 스크립트 매핑 — `+mn-ea`로 참조된 텍스트 전부 이 폰트로 렌더링됨)
- 캡션 일부(아이템명 등): **나눔고딕** 명시적으로 지정된 곳 존재 (4곳)
- 크기 구간: 7~9pt(본문/캡션), 10~11pt(굵게, 소제목), 14~16pt(섹션 타이틀), 28pt(페이지 대제목)
- 강조색: 빨강(FF0000) 9pt bold — 유의사항/경고성 텍스트에 사용

## 색상
테마 accent (Office 기본 테마 그대로, 커스텀 브랜드 팔레트 아님):

샘플에서 직접 발견된 명시적 RGB (배지/강조용으로 추정, 3단계에서 실사용 위치 재확인 필요):
- `FFF2CC` — 옅은 노랑 (하이라이트 배경 추정)
- `7030A0` — 보라 (배지 추정)

⚠️ **한계 (렌더러 작업 때 해소됨, 아래 참고)**: 도형 fill 중 상당수가 테마 스킴 참조라
`fill_rgb`로 못 잡혔음 — 슬라이드 7/8 XML을 직접 열어 schemeClr을 수동으로 역산해서 해결.

## 렌더러용 확정 스타일 값 (슬라이드 7/8 XML 직접 역산, scheme color 포함)

이 값들은 python-pptx의 `fill.fore_color.rgb`로는 안 잡히는 schemeClr 참조를 XML에서
직접 읽어 표준 Office 스와치 공식으로 환산한 것. `tools/render_pptx.py`가 이 값을 사용함.

| 요소 | 값 | 근거 |
|---|---|---|
| 카드(아이콘 프레임) 배경 | `FFFFFF` (흰색) | `roundRect`, `<a:solidFill><a:schemeClr val="bg1"/>` |
| 카드 테두리 | `BFBFBF` (연회색) | `schemeClr val="bg1" lumMod=75%` = "Background 1, Darker 25%" 표준 스와치, 두께 0.25pt |
| 카드 모서리 반경 | ~9.5% (`adj≈9481`) | `prstGeom prst="roundRect"` |
| 캡션 텍스트 색 | `262626` (순검정 아님) | `schemeClr val="tx1" lumMod=85% lumOff=15%` = "Text 1, Lighter 15%" 표준 스와치 |
| 캡션 폰트/크기 | 맑은 고딕, 7~9pt | 섹션마다 7pt(그리드)~9pt(new_highlight) 혼재, 렌더러는 8pt로 통일 |
| 섹션 헤더바 배경 | `404040` (진회색), `roundRect` | `schemeClr val="tx1" lumMod=75% lumOff=25%` = "Text 1, Lighter 25%" 표준 스와치 |
| 섹션 헤더바 텍스트 | `FFFFFF`, 16pt bold | `schemeClr val="bg1"` 직접 참조 |
| NEW 배지 | 도형 아님 — 빨강(`FF0000`) 굵은 글씨만, 배경 없음, 대각선 회전(~-18°) | `<a:t>NEW</a:t>` 런에 `srgbClr val="FF0000"`, `rot="20524426"` (60000분의1도 단위) |

이 표는 `master_template_raw.json`을 다시 열지 않고도 렌더러가 참조할 수 있는 최종본.

## 블록 관련 슬라이드 구조 (레이아웃: `[AS]공지형`, 페이지 1/4~4/4)

공통 요소 (6~9번 슬라이드 전부 반복):
- 우측 상단 고정 등급표: `표 7` @ (721.6, 37.2), 238.1 x 184.8pt — 고정 필드 영역, AI/블록엔진 손대지 않음
- 상단 타이틀바 텍스트 개체 틀 4종 (제목/기간/페이지표기 등), 페이지 번호 하단 고정

**정정 (2단계에서 발견)**: 슬라이드 6의 이미지 3장(94~113pt 폭)은 **10개월 전수 확인 결과
매달 크기가 100% 동일** — 매달 바뀌는 블록 콘텐츠가 아니라 고정 장식 일러스트임. 블록 엔진
대상에서 제외. 실제 가변 블록은 **슬라이드 7부터** 시작하며, 페이지 수(1/N~N/N)는 월별
항목 개수에 따라 2~5페이지로 달라짐 (박스 초과 시 다음 슬라이드 이월 원칙과 일치).

슬라이드별 콘텐츠 영역 (박스 좌표는 `master_template_summary.json` slides[].top_level_shapes 참고):

| 슬라이드 | 페이지 | 콘텐츠 패턴 | 블록타입 |
|---|---|---|---|
| 6 | 1/4 | 고정 등급표 + 고정 장식 이미지 3개 (매달 불변) | 블록 아님 (고정) |
| 7 | 2/4 | 기간제 패키지, 24x24pt 소형 아이콘 6개가 3열x2행 그리드 (라운드박스+캡션) | **A (아이콘그리드)** — 확정 |
| 8 | 3/4 | 표 3개, 91.6pt/72.3pt 이미지 2개, "NEW" 배지 텍스트 실제 검출 | **B' (NEW강조+리스트)** — 확정 |
| 9 | 4/4 | 유의사항 텍스트 위주, 그리드 콘텐츠 없음 (마지막 안내 페이지) | 블록 아님 (고정 텍스트 영역) |

10개월 전수 분류 결과는 [block_type_classification.md](block_type_classification.md) 참고
